📊 MÉTRICAS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════

const stats = await window.electronAPI.getUpdateStats();
Retorna:
  • totalChecks: número de verificaciones
  • totalUpdates: actualizaciones completadas
  • updateAttempts: intentos actuales
  • crashesDetected: crashes post-actualización

const telemetry = await window.electronAPI.getTelemetryData();
Retorna:
  • stats: estadísticas agregadas
  • recentLogs: últimos 50 eventos
  • version: versión actual

🎯 CARACTERÍSTICAS CLAVE
═══════════════════════════════════════════════════════════════════════════

✓ DETECCIÓN DE CRASHES
  • Detecta si app crashea tras actualizar
  • Registra cada intento fallido
  • Después de 2 fallos → rollback automático

✓ PROGRESS VISUAL
  • Barra de progreso con %
  • Datos: MB transferidos / total
  • Velocidad: MB/s
  • Tiempo: Estimado restante

✓ VERSIONADO AUTOMÁTICO
  • npm run version -- major|minor|patch
  • Actualiza package.json automáticamente
  • Genera entrada en CHANGELOG.md
  • Crea git tag

✓ PUBLICACIÓN MULTI-CANAL
  • stable: Release normal
  • beta: Pre-release
  • edge: Draft (invisible)

✓ LOGGING CENTRALIZADO
  • JSON por línea en archivo
  • Timestamps ISO
  • 9 tipos de eventos
  • Acceso vía getTelemetryData()
